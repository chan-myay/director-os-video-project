# Director OS Skills

Skills are reusable directing presets. They shape autonomous planning but do not
execute generation, upload media, or bypass approval gates.

Available presets:

- `cinematic_music_video`
- `performance_music_video`
- `narrative_music_video`
- `narrative_short`
- `commercial_ad`
- `product_film`
- `documentary`
- `lyric_video`
- `social_short`
- `interview`
- `cinematic_trailer`
- `burmese_winter_bar_music_video`

The project-specific Burmese winter bar skill stores lessons and creative locks,
not private identity files for unrelated projects.
