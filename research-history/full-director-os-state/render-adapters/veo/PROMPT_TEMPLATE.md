# Veo Adapter Template

Status: template only. Do not use Gemini/Flow/Veo or create final prompts yet.

Later mapping from `RENDERER_FIELDS.yaml`:

- `references` -> approved reference image set
- `intent` -> one shot / one action
- `motion` -> visible principal action
- `camera_lighting` -> shot scale and lighting
- `negative_rules` -> avoid list

No API call or Flow/Gemini use is permitted in v0.1.
