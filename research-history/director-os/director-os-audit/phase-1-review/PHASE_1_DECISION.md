# Phase 1 Decision

Recommendation: A) local recut first.

## Why

The project already has enough selected material to improve the diagnostic edit
without spending credits or touching cloud tools:

- Batch A can cover weak face and lip moments.
- Batch B can add movement and room geography if treated as movement-only.
- Batch C can be reduced to emotional punctuation and face-correction
  placeholders.
- Batch D is the current dance core and can be arranged more carefully.
- v2B's biggest immediate problem is editorial repetition and exposed risk, not
  a missing renderer setup.

Face correction should wait until the v2C timeline is tighter, because
correcting shots before the edit changes would waste effort. Future generation
should also wait, because the exact missing shots need to be proven by a local
recut first.

## Practical Action

Use `V2C_EDIT_DECISION_LIST_DRAFT.csv` as a paper timeline. Do not render until
the timeline is reviewed and the risky face shots are either removed, covered,
or flagged for correction.
