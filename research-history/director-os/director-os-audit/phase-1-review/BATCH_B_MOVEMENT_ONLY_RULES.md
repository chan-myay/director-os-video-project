# Batch B Movement-Only Rules

Global rule: Batch B faces are not trusted. Use Batch B primarily for movement,
stage geography, curtains, aisle travel, hands, rose, and body coverage. Avoid
clear close face use unless local HiFiFace/UniFace correction later passes.

less static, but it must not carry lead performer identity, mouth performance, or hero
