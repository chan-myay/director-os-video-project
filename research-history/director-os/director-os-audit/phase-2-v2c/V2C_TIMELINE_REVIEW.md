## Repeated D03 / D04 / D06 Use

The Phase 1 EDL repeats the only strong dance core often:

- D03 appears repeatedly for side/profile/wide movement.
- D04 appears repeatedly as the safest silhouette.
- D06 appears repeatedly as the strongest chorus body material.

This is unavoidable with current selected footage, but v2C should reduce
visible repetition by separating repeated D clips with Batch A objects, B03/B04
movement-only coverage, and short D05 accents.

Safe adjustment:

- Keep D03 as the primary movement clip but avoid back-to-back use.
- Keep D04 as the main face-safe chorus/later-verse silhouette.
- Use D06 only in trimmed form and only at chorus power points.

## Risky Batch B Face Exposure

Risky draft entries:

- B04 aisle travel
- B05 aisle travel
- B06 return to stage
- B08 curtain exit
- B07 rose placement if the face becomes clear

Safe adjustment:

- Treat all Batch B as movement/stage/body/object only.
- Use shorter segments where possible.
- Place object cutaways before/after Batch B to avoid identity reads.
- Do not rely on Batch B for lead performer identity or lip-sync.

## Risky Batch C Face Exposure

Risky draft entries:

- C01 medium face
- C06 close/medium emotional hold
- C07 profile memory trim
- C08 close eye/detail

Safe adjustment:

- Remove C01 and C06 from the safe EDL for now.
- Keep C07 only as brief profile punctuation.
- Keep C08 only as an eye/detail placeholder.
- Use C09 only wide/medium if a stage continuity placeholder is needed.
- Do not use any Batch C close face as approved final identity.

## Weak C05 / Fake Mouth Usage

The Phase 1 EDL did not include C05, which is correct.

Safe adjustment:

- Keep C05 out of v2C.
- Do not use it as lip-sync.
- If ever used later, it must be heavily hidden or corrected after explicit
  review, but not in this safe recut package.

## Object Cutaways Replacing Face Risk

Places where objects should replace face-risk shots:

- Replace C01 verse emotion with A04/A08/B02/D04 coverage.
- Replace C06 final chorus hold with A03/A05/A07/D04.
- Use A03, A04, A05, A07, A08, A09, and A10 around Batch B identity-risk shots.
- Use A10 only at the ending so the microphone stays symbolic.

## Static Or Repeated Sections

Sections still at risk:

- Verse 1 can become D03/D04/B movement repetition.
- Chorus 1 can become D04/D06 repetition.
- Later verse can become B travel plus repeated D03/D04.
- Final chorus can become repeated D04/D06/D03.

Safe adjustment:

- Keep cuts shorter in high-energy sections.
- Use Batch A objects as rhythmic punctuation.
- Use D05 maximum two short times.
- Prefer silhouette/body/object over close face.

## Practical v2C Direction

The safe v2C EDL should be more conservative than Phase 1:

- fewer Batch C face placeholders
- no C05
- no C01/C06 close/medium emotional holds
- Batch B only as movement/object/stage
- D05 only two short accents
- D06 only trimmed before face close
- microphone only as ending symbol
