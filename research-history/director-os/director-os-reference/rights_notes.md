# Rights Notes

Director OS reference library stores reference maps, not unauthorized media
archives.

## Default Rule

For third-party reference sites and public video sites:

- Store URL.
- Store title/source.
- Store tags and notes.
- Store composition, lighting, motion, and cultural analysis.
- Do not copy or rehost stills/videos.

## User-Owned Media

User-owned uploads may be stored only with:

- owner
- consent status
- rights status
- allowed project
- allowed connector/upload policy

## Public SaaS Requirement

Before public launch, build:

- takedown process
- rights complaint intake
- asset deletion/export
- per-project isolation
- audit logs for upload and connector use
