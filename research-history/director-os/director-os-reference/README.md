# Director OS Reference Library

Rights-aware reference library for cinematography, motion, culture, lighting,
and moodboards.

v0.3 stores metadata and search templates only. It does not scrape, download, or
rehost copyrighted reference images or videos.

## Core Objects

- Reference source
- URL
- Tags
- Rights notes
- Composition analysis
- Motion notes
- Cultural notes
- Shot-pack relationship

## Rule

User-owned uploads are allowed only with rights metadata. Third-party reference
sites remain link-and-analysis records unless storage rights are documented.
