# Reference Library Strategy

The reference library is a rights-aware map of inspiration, not a scraped image
dump.

## Supported Reference Sources

- ShotDeck
- Shot.Cafe
- Flim.ai
- Film Vibes
- Frameset
- FilmGrab
- MovieStillsDB
- YouTube/Vimeo manual reference workflow
- User-owned uploads

## Rights Rule

Do not copy or rehost copyrighted stills from reference sites.

Store:

- URL
- Title/source name
- Rights notes
- Tags
- Composition notes
- Lighting notes
- Camera notes
- Color notes
- Cultural notes
- Why it matters to a shot pack

Only store media files when:

- User owns the file, or
- license permits storage, or
- explicit permission is documented.

## Moodboards As Reference Maps

A moodboard is a structured map:

- Reference URL
- Shot-pack relationship
- Composition analysis
- Motion intent
- Cultural relevance
- Do-not-copy warning

## YouTube / Vimeo Workflow

- Store links and timecodes.
- Store notes and tags.
- Do not download or rehost copyrighted videos by default.
- If a user owns the video or has license, store rights metadata before import.

## Public SaaS Implication

Reference libraries need takedown tools, rights metadata, and per-project
visibility controls from day one.
