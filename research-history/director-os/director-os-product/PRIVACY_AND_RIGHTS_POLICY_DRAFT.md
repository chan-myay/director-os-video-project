# Privacy And Rights Policy Draft

## Consent

Real people require documented consent before their face, body, voice, or
likeness is used for generation, face correction, voice cloning, or public
output.

## Child-Containing Sources

Child-containing sources are blocked from identity conditioning, generated-scene
inputs, upload packages, and public SaaS processing unless a separate lawful,
guardian-approved, child-safe workflow is designed. This project excludes them.

## Rejected References

Rejected lead performer reference sheets are evidence only. They must not be uploaded,
used for generation, or included in active request packages.

## Private Source Folders

Broad private lead performer/source folders must never be uploaded. Only exact approved
files may be used, and only after manual approval.

## Third-Party Uploads

Before uploading to any renderer:

- user approves renderer
- user approves exact files
- user approves final request
- user approves spend limit
- user acknowledges privacy risk

## Reference-Site Rights

Do not copy or rehost copyrighted reference stills or videos from ShotDeck,
Shot.Cafe, Flim.ai, Film Vibes, Frameset, FilmGrab, MovieStillsDB, YouTube, or
Vimeo unless rights permit it.

Store links, tags, notes, and analysis instead.

## Public SaaS User Data Isolation

- Each user belongs to an isolated project/workspace.
- Assets are scoped to one project unless deliberately shared.
- Audit logs record access, upload approval, connector use, and deletion.
- Admin access requires logging and justification.

## Takedown And Deletion

Public SaaS needs rights complaints, data export, project deletion, and media
deletion workflows before public launch.
