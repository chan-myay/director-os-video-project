# Web v0.6B Report

## Result Import

v0.6B adds local generated-result intake. A user can import a manually generated
video file from disk, link it to a shot pack, job, and manual export, and store
it under managed local result storage.

No renderer API is called. No file is uploaded to a third-party service. No
video is generated by Director OS.

## Storage Location

Imported results are stored under:

`director-os-web/result-media/<project>/<shot_id>/<result_id>/`

Each result folder contains:

- managed local video copy
- `metadata.json`
- `poster.jpg`
- `contact-sheet.jpg`
- `IMPORT_RECORD.md`
- `QC_RESULT.md`
- `DECISION.md`
- `PROMOTION_MANIFEST.yaml` only if accepted

Existing result folders are never overwritten.

## Media Analysis

Local ffmpeg/ffprobe are used when available. The importer extracts:

- duration
- width/height
- fps
- codec
- file size
- SHA-256
- poster frame
- contact sheet

No cloud analysis or OCR is used.

## QC

The result QC form records 0-10 scores for identity, face safety, body,
movement, choreography, dress, bar/location, Burmese cultural authenticity,
camera, lighting, limbs, fabric, song usefulness, and world-class readiness.

Critical gates cover kung fu/martial arts drift, K-pop/TikTok drift,
karaoke/lounge staging, fake lip-sync, microphone-centered staging, fake body
distortion, wrong dress, wrong venue, dangerous face failure, and normal-speed
review.

## Decision Rules

Allowed decisions:

- accept
- reject
- needs recut
- needs face correction
- archive

Accepted status is blocked unless the latest QC review exists and has no
critical failures.

Rejected decisions require a reason or failure tag.

## Promotion Manifest

Accepted results receive:

`PROMOTION_MANIFEST.yaml`

It records source result, usable time range, intended song section,
face-correction requirement, edit notes, and approval timestamp. It does not
modify the music-video edit.

## Test Data Isolation

Smoke tests use:

`director-os-web/data/director_os_test.sqlite`

The normal development database remains:

`director-os-web/data/director_os.sqlite`

The smoke test checks that development database table counts do not change.

## Security

- Filename sanitization.
- Path traversal prevention for served result media.
- Accepted extensions: mp4, mov, webm.
- Local size limit enforced.
- Uploaded/imported files are not executed.
- Result media route serves only files beneath `result-media`.

## Routes

- `/results`
- `/results/import`
- `/results/{result_id}`
- `/results/{result_id}/review`
- `/results/{result_id}/decision`
- `/jobs/F01_side_travel_dance/{job_id}/results`
